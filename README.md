# ParkMe

Smart parking finder app built with C#/.NET and React.

## About

ParkMe helps drivers find nearby parking options based on location, distance, and price.  
The goal of the project is to make parking search faster, easier, and less stressful, especially in busy urban areas.

## Main Features

- Search for nearby parking spots
- Compare parking options by distance and price
- Choose between closest, cheapest, or balanced recommendations
- View basic parking details
- Navigate to the selected parking location

## Tech Stack

- Backend: C# / .NET
- Frontend: React
- Database: vecal
